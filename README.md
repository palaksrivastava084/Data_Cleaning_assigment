Project Title: Palmerpenguins Data Cleaning and Exploratory Analysis
Description: This project performs comprehensive data cleaning, missing value treatment, feature encoding, and exploratory data analysis (EDA) on the palmerpenguins dataset using R.
Tools & Libraries Used: R, Tidyverse, Palmerpenguins, Naniar, FastDummies, and Corrplot.
Author: Palak Srivastava
