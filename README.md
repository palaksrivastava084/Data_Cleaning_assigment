# Palmerpenguins Data Cleaning and Exploratory Analysis

## Project Overview
This project performs comprehensive data cleaning, missing value treatment, feature encoding, and exploratory data analysis (EDA) on the `palmerpenguins` dataset using R.

## Tools & Libraries Used
- **R** & **RMarkdown**
- **Tidyverse** (for data manipulation)
- **Palmerpenguins** (dataset source)
- **Naniar** (for missing value visualization and treatment)
- **FastDummies** (for categorical variable encoding)
- **Corrplot** & **ggplot2** (for correlation and data visualization)

## Key Steps Performed
1. **Data Loading & Inspection:** Loaded the penguins dataset and inspected structure, column names, and summary statistics.
2. **Missing Value Treatment:** Identified missing values using `naniar` and handled them appropriately to ensure clean data for analysis.
3. **Feature Engineering & Encoding:** Converted categorical variables into numerical/dummy variables using `fastDummies`.
4. **Exploratory Data Analysis (EDA):** Generated correlation plots and visual graphs using `ggplot2` to analyze relationships between body mass, flipper length, bill dimensions, and species.

## Conclusion
The cleaned dataset is now fully prepared and optimized for predictive modeling and advanced analytics.
